# indentation

行のインデントが開いているどのブロックにも合わない、またはタブを含む。

コンパイラーが報告するエラーです。直すまでプログラムはビルドできません。

## 理由

ブロックは波括弧の代わりにインデントでも書けます。深い行がブロックを開き、インデントが戻ったところでブロックが終わります。そのため、行は開いているブロックのインデントに戻らなければならず、そうでないとスキャナーはその行がどのブロックに属するのか判断できません。インデントはスペースで書きます。タブの幅はエディターごとに違うからです。

## 直し方

その行を属するブロックにそろえます（そのブロックの前の行と同じインデントにします）。あるいはブロックを波括弧で書きます。インデントにはスペースを使います。

## 誤った例

```asuka
fn sign(a: int) -> int
  if a < 0
      return -1
    return 1
```

## 正しい例

```asuka
fn sign(a: int) -> int
  if a < 0
    return -1
  return 1
```
