# indentation

某行的缩进对不上任何打开的块，或者含有制表符。

编译器报告的错误：修正之前程序无法构建。

## 原因

块既可以用花括号写，也可以用缩进写：更深的一行打开块，缩进退回的地方块就结束。所以一行必须退回到某个打开的块的缩进，否则扫描器分不清它属于哪个块。缩进要用空格：制表符在每个编辑器里宽度都不一样。

## 如何修正

把这一行和它所属的块对齐（与该块前面几行的缩进相同），或者改用花括号写这个块。用空格缩进。

## 错误示例

```asuka
fn sign(a: int) -> int
  if a < 0
      return -1
    return 1
```

## 正确示例

```asuka
fn sign(a: int) -> int
  if a < 0
    return -1
  return 1
```
